## 🎯 ПЛАН РАЗРАБОТКИ (СРОЧНО!)

### Этап 1: Инфраструктура (30 мин)
```
1. Создай monorepo структуру с Turborepo
2. Настрой базовые package.json для всех приложений
3. Настрой TypeScript конфигурации
4. Создай базовую папочную структуру согласно docs/architecture.md
```

### Этап 2: База данных (45 мин)  
```
1. Настрой Prisma schema с моделями из docs/database-schema.md
2. Создай миграции
3. Реализуй seed.ts с 39 товарами VMC из packages/database/seed.ts
4. Проверь, что все 65 характеристик правильно настроены
```

### Этап 3: API Backend (60 мин)
```
1. Создай Express API согласно docs/api.md
2. Реализуй все endpoints (публичные + админские)
3. Настрой аутентификацию для админки
4. Добавь валидацию через Zod
5. Настрой CORS и middleware
```

### Этап 4: Админка (90 мин)
```
1. Создай Next.js админ приложение
2. Настрой NextAuth.js для входа
3. Создай формы CRUD для товаров с 65 характеристиками
4. Добавь управление категориями
5. Реализуй загрузку изображений
6. Используй Tailwind UI компоненты
```

### Этап 5: Публичная часть (90 мин)
```
1. Создай Next.js публичное приложение
2. Реализуй главную страницу с категориями
3. Создай страницы категорий с товарами
4. Сделай детальные страницы товаров с галереей
5. Добавь поиск (базовый, потом Algolia)
6. Примени дизайн-систему VMC (красный #EC2834, черный #1E1E1E)
```

### Этап 6: Полировка (60 мин)
```
1. Добавь сравнение товаров
2. Оптимизируй загрузку изображений
3. Настрой мобильную адаптацию
4. Добавь анимации Framer Motion
5. Проверь все функции
```

## 📊 КЛЮЧЕВЫЕ ДАННЫЕ

- **39 товаров**: 23 скутера, 5 мопедов, 6 мотоциклов, 5 питбайков
- **65 характеристик** для каждого товара (от завода изготовителя до документов)
- **4 категории**: Скутера, Мопеды, Мотоциклы, Питбайки
- **1 админ**: простая система без ролей
- **Без регистрации**: открытый доступ к каталогу

## ⚡ ВАЖНЫЕ ТЕХНИЧЕСКИЕ МОМЕНТЫ

1. **Монорепо**: apps/web, apps/admin, apps/api + packages/ui, packages/database
2. **База**: PostgreSQL + Prisma ORM + seed с реальными товарами
3. **Frontend**: Next.js 14+ App Router + TypeScript + Tailwind CSS + Tailwind UI
4. **Backend**: Express + JWT + Zod validation
5. **Фото**: локальное хранение, Next.js Image optimization
6. **Поиск**: сначала базовый, потом Algolia

## 🚨 КРИТИЧЕСКИ ВАЖНО

- **СРОКИ ГОРЯТ** - делай быстро, но качественно
- **MVP сначала** - основной функционал, потом фишки
- **Используй готовые решения** - Tailwind UI, не изобретай велосипед
- **Обращайся к документации** - вся инфа есть в docs/
