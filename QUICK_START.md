## 🎯 План действий (СРОЧНО!)

### Шаг 1: Подготовка проекта (5 мин)
```bash
# Создание проекта
mkdir vmc-manager-handbook
cd vmc-manager-handbook

# Инициализация
npm init -y
```

### Шаг 3: Базовая настройка (15 мин)

#### turbo.json
```json
{
  "$schema": "https://turbo.build/schema.json",
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {},
    "test": {}
  }
}
```

#### package.json
```json
{
  "name": "vmc-manager-handbook",
  "private": true,
  "workspaces": [
    "apps/*",
    "packages/*"
  ],
  "scripts": {
    "dev": "turbo run dev --parallel",
    "build": "turbo run build",
    "start": "turbo run start",
    "lint": "turbo run lint",
    "db:push": "cd packages/database && npx prisma db push",
    "db:seed": "cd packages/database && npx prisma db seed",
    "db:studio": "cd packages/database && npx prisma studio"
  },
  "devDependencies": {
    "turbo": "^1.10.0"
  }
}
```

#### .env.example
```bash
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/vmc_handbook"

# API
JWT_SECRET="super-secret-jwt-key"
API_PORT=8000

# Next.js
NEXT_PUBLIC_API_URL="http://localhost:8000"

# Algolia (опционально)
ALGOLIA_APP_ID=""
ALGOLIA_API_KEY=""
NEXT_PUBLIC_ALGOLIA_SEARCH_KEY=""
```
