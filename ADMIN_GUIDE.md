# VMC Учебник - Руководство администратора

## 🎯 Обзор проекта
Внутренний каталог мототехники VMC для изучения товаров менеджерами компании. Проект включает 39 товаров с детальными характеристиками (65+ параметров каждый).

## 🏗️ Архитектура
- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express + PostgreSQL + Prisma ORM
- **Admin Panel**: React Admin
- **Монорепозиторий**: Turborepo

## 🚀 Быстрый старт

### 1. Запуск всех сервисов
```bash
# Терминал 1: API сервер
cd apps/api && npm run dev
# Работает на http://localhost:8000

# Терминал 2: Админка
cd apps/admin && npm run dev  
# Работает на http://localhost:3001

# Терминал 3: Публичная часть
cd apps/web && npm run dev
# Работает на http://localhost:3000
```

### 2. Доступ к системам
- **Публичный каталог**: http://localhost:3000
- **Админка**: http://localhost:3001
- **API**: http://localhost:8000

## 🔧 Админка (React Admin)

### Вход в систему
- **URL**: http://localhost:3001
- **Логин**: marketing@benzo.ru
- **Пароль**: admin123

### Управление товарами
1. **Создание товара**
   - Нажмите "Создать" в списке товаров
   - Заполните основные поля (название, описание, категория)
   - Добавьте изображения (URL или загрузка файлов)
   - Заполните характеристики (65+ полей)

2. **Редактирование товара**
   - Нажмите на товар в списке
   - Измените нужные поля
   - Характеристики обновляются автоматически

3. **Удаление товара**
   - Нажмите "Удалить" в карточке товара
   - Подтвердите действие

### Управление категориями
- Создание новых категорий
- Редактирование названий и описаний
- Удаление (только если нет товаров)

### Управление характеристиками
- **65 предустановленных характеристик**
- Автоматическое создание для каждого товара
- Редактирование значений через форму товара
- Группировка по категориям (двигатель, ходовая, электрика)

## 🔌 API Endpoints

### Публичные эндпоинты
```
GET /api/categories - список категорий
GET /api/categories/:id - категория по ID
GET /api/products - список товаров
GET /api/products/:id - товар по ID
```

### Админские эндпоинты (требуют аутентификации)
```
POST /api/auth/login - вход в админку
POST /api/products - создание товара
PUT /api/products/:id - обновление товара
DELETE /api/products/:id - удаление товара
POST /api/categories - создание категории
PUT /api/categories/:id - обновление категории
DELETE /api/categories/:id - удаление категории
```
