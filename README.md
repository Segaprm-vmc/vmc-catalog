 
# VMC Учебник для менеджеров

Внутренний каталог мототехники VMC для изучения товаров менеджерами компании.

## 🏍️ О проекте

**VMC Учебник** - это веб-приложение для изучения мототехники компании VMC. Содержит каталог из 39+ товаров в категориях: Скутера, Мопеды, Мотоциклы, Питбайки. Каждый товар содержит детальные характеристики (65+ полей), фотогалерею и видео.

### Основные возможности:
- 📋 Каталог товаров по категориям
- 🔍 Поиск по названиям товаров
- 📊 Детальные характеристики (65 параметров)
- 🖼️ Фотогалереи с каруселью
- 🎥 Встроенные видео (YouTube/VK)
- ⚖️ Сравнение товаров
- 🛠️ Админка для управления контентом

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- PostgreSQL 15+
- npm или yarn

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd vmc-manager-handbook

# Установка зависимостей
npm install

# Настройка переменных окружения
cp .env.example .env.local
# Отредактируйте .env.local с вашими настройками

# Настройка базы данных
npx prisma migrate dev
npx prisma db seed

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно:
- Публичная часть: http://localhost:3000
- Админка: http://localhost:3001
- API: http://localhost:8000

### База данных
```sql
-- Проверка количества товаров
SELECT c.name, COUNT(p.id) as count 
FROM categories c 
LEFT JOIN products p ON c.id = p.category_id 
GROUP BY c.id, c.name;

-- Поиск товаров без характеристик
SELECT p.name FROM products p 
LEFT JOIN product_characteristics pc ON p.id = pc.product_id 
WHERE pc.id IS NULL;
```

## ❓ FAQ

### Как добавить новый товар?
1. Зайдите в админку `/admin/login`
2. Перейдите в "Товары" → "Добавить товар"
3. Заполните форму и характеристики
4. Загрузите фотографии
5. Сохраните

### Как изменить категории?
Категории управляются через админку в разделе "Категории"

### Как добавить характеристику?
Все 65 характеристик уже предустановлены. Просто заполните нужные значения при создании товара.

### Как настроить поиск?
Поиск работает через Algolia. Настройте ключи в переменных окружения.
